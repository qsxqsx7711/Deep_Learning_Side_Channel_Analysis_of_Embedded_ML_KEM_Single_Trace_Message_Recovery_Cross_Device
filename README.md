# ML-KEM Unfixed Message Dataset

> **Dataset used in the paper:** The power-trace dataset used in the experiments reported in the associated paper is available from the [GitHub dataset release](https://github.com/qsxqsx7711/Deep_Learning_Side_Channel_Analysis_of_Embedded_ML_KEM_Single_Trace_Message_Recovery_Cross_Device/releases/tag/dataset).

## Overview

This release provides side-channel power traces collected during the execution of the ML-KEM `poly_frommsg()` operation using randomly generated 32-byte messages. The dataset supports single-trace message-recovery experiments and cross-device evaluation.

## Dataset summary

- Target device: STM32F415 on ChipWhisperer CW308
- Oscilloscope: PicoScope 5244B
- Device clock: 7.37 MHz
- Sampling rate: 500 MS/s
- Profiling device: D0
- Attack devices: D1, D2, and D3

Download the dataset from the [GitHub Release Assets](https://github.com/qsxqsx7711/Deep_Learning_Side_Channel_Analysis_of_Embedded_ML_KEM_Single_Trace_Message_Recovery_Cross_Device/releases/tag/dataset).
